03 / MAKE IT YOURS

A better workflow.
In your next project.

Clone the full repository, then choose your coding agent and install the five skills into your app. You can also download the complete source ZIP. Node.js 20 or newer is required.

Download toolkit ZIP ↓

Includes all five skills, templates, CLI tools, tests, examples, and the MIT license. The workflows guide your coding agent; this page does not run an AI model. Read the setup guide ↗

git clone https://github.com/TurboTwitch0/INTERFACE-FOUNDRY.git
cd INTERFACE-FOUNDRY
node bin/foundry.mjs init /path/to/app --agent claude

Installs into your app’s .claude/skills/ directory.

04 / YOUR OWN CORNER OF THE WEB

The full project. Ready to build.

Import INTERFACE-FOUNDRY into Vercel or Netlify. The repository includes the source, skill content, build script, and hosting configuration for both platforms.

  1. Connect your GitHub account and select this repository.
  2. Keep the repository root as the project directory.
  3. Deploy with npm run build and output directory dist. The included platform configurations set these values.

The build creates the website, skill data, and downloadable source ZIP. No environment variables or backend services are required. The example notes reset on reload.
