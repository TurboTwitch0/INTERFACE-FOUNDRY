03 / MAKE IT YOURS

A better workflow.
In your next project.

Download the complete toolkit ZIP below and extract it. Open a terminal in the extracted folder, then choose your coding agent and run the commands. Node.js 20 or newer is required.

Includes all five skills, templates, CLI tools, examples, and MIT license. The workflows guide your coding agent; this page does not run an AI model.

cd interface-foundry
node bin/foundry.mjs doctor
node bin/foundry.mjs init /path/to/app --agent claude

04 / YOUR OWN CORNER OF THE WEB

One file. Ready to share.

This page works by itself, including the complete downloadable toolkit. Upload this file as index.html at the root of your own GitHub repository. Then import that repository into Vercel.

  1. Choose the Other framework preset.
  2. Keep the root directory at the repository root. Override the build command and leave it empty.
  3. Leave the output directory at its default (root . for this repository) and deploy.

No package installation, environment variables, or extra files are needed to host this page. The example notes reset on reload.
