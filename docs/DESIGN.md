# Interface Foundry visual direction

The design takes cues from the product-page example in the public cover of the
[reference Reel](https://www.instagram.com/reel/DdshHpFpqdi/): a layered mint field,
oversized quiet lettering, one dominant floating object, and sharp dark labels.
The cover was observed directly. Full video playback was unavailable.

The hero uses original glass interface artwork rather than the reference's shoe
or branding. Local Barlow Condensed and Space Grotesk fonts establish a strong
display/body hierarchy; their OFL licenses and source URLs live in
`assets/fonts/`. The dark workflow section creates a clear change of pace after
the bright hero. The lab and installation section retain the product's working
controls and actual source download.

The page remains a static application built into `dist`. Fonts, artwork, styles,
scripts, skill text, and downloads are served from the same site. There is no
third-party asset dependency or live AI service in the website.

Verification covers the build, source references, downloadable archive, HTTP
resources, and interaction logic. Rendered-browser comparison is unavailable in
this session and must not be described as passed.
